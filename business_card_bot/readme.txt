# Бот-визитка (aiogram 3)

Простой Telegram-бот для портфолио: главное меню с услугами, прайсом,
контактами и портфолио на inline-кнопках.

## Структура проекта

```
business_card_bot/
├── main.py          # точка входа, запуск бота
├── config.py        # чтение токена из .env
├── handlers.py       # вся логика: команды и обработка кнопок
├── keyboards.py       # inline-клавиатуры
├── requirements.txt   # зависимости
└── .env.example       # пример файла с токеном
```

## Как запустить

### 1. Получи токен бота
Напиши в Telegram боту **@BotFather**, отправь `/newbot`, следуй инструкциям —
он выдаст тебе токен вида `123456:ABC-DEF1234...`.

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

(рекомендуется делать это в виртуальном окружении:
`python -m venv venv` → `source venv/bin/activate` на Linux/Mac
или `venv\Scripts\activate` на Windows)

### 3. Настрой токен

Скопируй `.env.example` в `.env`:

```bash
cp .env.example .env
```

Открой `.env` и вставь свой токен вместо заглушки:

```
BOT_TOKEN=123456:ABC-DEF1234...
```

### 4. Запусти бота

```bash
python main.py
```

Если всё сделано верно, в консоли появится лог о старте, а в Telegram
можно будет написать боту `/start`.

## Что можно доработать дальше (для портфолио)

- Заменить тексты и услуги на реальные данные заказчика.
- Добавить отправку фото/документов (например, прайс-лист PDF).
- Подключить БД, чтобы сохранять, кто и когда нажимал на кнопки
  (простая аналитика для заказчика).
- Добавить админ-команду, которая рассылает сообщение всем пользователям бота.
